# The Growth Room

Website for The Growth Room, a transformative life coaching practice. It's a plain HTML/CSS/JS site (no build step), hosted on GitHub Pages.

- `index.html`: page content
- `assets/styles.css`: design
- `assets/script.js`: booking link, contact email, interactions
- `images/`: add `logo.png` and `headshot.jpg` here

See **[SETUP.md](SETUP.md)** for adding photos, connecting your domain and setting up bookings and payments.
