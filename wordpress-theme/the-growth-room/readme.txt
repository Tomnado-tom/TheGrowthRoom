== Changelog ==

= 1.2.0 =
* Dark mode: when a visitor's device is set to dark, the site uses its own dark colours and a light-lettered logo. Light mode is unchanged.
* Browsers are told the site has its own dark design, so they no longer auto-darken it.

= 1.1.5 =
* The calendar is now added above your own text in the Booking card instead of replacing it.
* Built-in contact email is thegrowthroomcoach@gmail.com.
* Empty tags under About Me are hidden.

= 1.1.4 =
* Logo stays top-left while the phone menu is open; close button lines up with the menu button.
* Header background is now solid cream (more reliable on phones than the frosted effect).

= 1.1.3 =
* Fix: the phone menu only showed "About"; it now opens full screen with every link.
* "Book a Session" added to the phone menu.

= 1.1.2 =
* Fix: the Calendly calendar could collapse to an empty bar when moving to the next step.

= 1.1.1 =
* Calendly calendar resizes to fit each booking step, so there's no inner scroll bar.

= 1.1.0 =
* Booking section shows the Calendly calendar, including on home pages already saved in the Site Editor.
* Coach's story, headshot (pink background removed) and logo added.
* Colours updated to match the logo.
* Larger header logo; welcome-section logo centred in its circle.
* White logo backgrounds blend into the page.

= 1.0.0 =
* First release.
